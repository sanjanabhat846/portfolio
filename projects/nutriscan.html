🥗 NutriScan AI

NutriScan AI is a Computer Vision application that recognizes food items from images and provides estimated nutritional information. The system helps users make healthier food choices using Artificial Intelligence.

Problem Statement

Many people are unaware of the nutritional value of the food they consume. Calculating calories manually is difficult and time-consuming.

Solution

Users upload a food image and the AI predicts the food category along with estimated calories, carbohydrates, proteins, and fats.

Key Features

  • Food image recognition
  • Calorie estimation
  • Nutritional information
  • Healthy eating recommendations
  • Simple and responsive interface

Technologies Used

  • Python
  • TensorFlow
  • Keras
  • OpenCV
  • Flask
  • HTML
  • CSS
  • JavaScript

Dataset

Food image datasets containing multiple food categories for training the deep learning model.
